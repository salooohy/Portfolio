1Basecamp

A training dashboard on my own Garmin data that puts effort next to recovery, with strength sessions logged by text message.

TypePersonal · 2026
Stack / processNext.js · Upstash Redis · Garmin Connect · Anthropic API · Vercel

What it answers

Basecamp puts my training effort next to my recovery: daily activity and workouts beside sleep, sleep score and HRV, with neither side treated as secondary. One glance should tell me whether today should be hard, easy or rest. The trend charts cover the weekly review.

Private repo · it shows my own health data, so there are no screenshots

Staying signed in

Garmin's login page sits behind Cloudflare bot detection, and serverless IPs routinely get a CAPTCHA no library can solve. So the deployed app never logs in. I run a login script once from home, it saves the session tokens to Upstash Redis, and the app reads them on every request and refreshes the short-lived access token itself.

Dashboard data is cached for 30 minutes so a page load never waits on Garmin. A refresh button and a daily cron force an early refresh, and if a refresh fails the page falls back to the last cached data and says so.

Strength logging by text

Garmin doesn't track strength sets the way I want, so I text a Telegram bot something like “bench 3x8 at 135, squats 5x5 225, felt strong”. Claude parses it into exercises, sets, reps and pounds, and it's logged exactly as if I'd filled in the form. The bot replies with the session as plain text, ready to paste into Strava.

Build

  • Next.js 16 with the App Router and Server Components, deployed on Vercel behind a password
  • Hand-built SVG charts, no chart library
  • Upstash Redis for Garmin tokens and the data cache
  • Anthropic API for parsing the Telegram messages
  • Data windows: steps over 28 days, sleep over 14 nights, the 15 latest activities, strength over 30 days
