2Finance tracker

Where my money goes, from real bank and card data, with Claude doing the categorizing and answering questions.

TypePersonal · 2026
Stack / processNext.js · Supabase · Plaid · Recharts · Anthropic API

What it answers

Opening it should answer one question at a glance: how much do I have left to spend this month, and am I on pace? Under that sits a weekly routine of clearing uncategorized transactions and checking trends.

Private repo · it runs on my real accounts, so there are no screenshots

How it works

  • Plaid syncs my bank and card accounts on demand. Every institution is Canadian, so everything is in CAD.
  • Claude categorizes new transactions, checking my own history first. Anything it isn't sure about stays uncategorized in a needs-review queue for me to clear.
  • Work and personal spending are split with a flag on each transaction, so work expenses never inflate the personal picture.
  • Insights chat answers questions about my money in plain language.
  • Transfers between my own accounts and credit card payments never count as spending or income, and month-to-month comparisons use the same days of the month.

Why a second version

It replaces version one, a Streamlit app that needed statement files dropped into a folder. Linking accounts directly removed that chore, and moving the categorizing to Claude removed most of the rest.

Build

  • Next.js 16 (App Router) and Tailwind v4
  • Supabase for auth and Postgres; single user, no sign-up page
  • Plaid, Recharts, Zod, and the Anthropic API
